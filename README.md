# Bio Click Done (BCD)

> A streamlined, secure PyQt desktop application for profile management, simplifying how users view and update personal and academic information.

---

## Features

* **Role-Based Access Control (RBAC):** Secure access levels for students, faculty, and administrators to protect sensitive records.
* **Profile Management:** Effortlessly view, edit, and update personal and academic profiles.
* **Responsive Desktop UI:** Built with PyQt to offer a modern, intuitive, and responsive user experience.
* **Data Security:** Strict validation and secure role handling to ensure data integrity.

---

## Prerequisites

Ensure you have the following installed on your machine:

* **Python 3.8+**
* **pip** (Python package installer)
